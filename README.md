# CareerPath.AI 🚀

CareerPath.AI is a small project that we made to help students who are confused about what they should learn for their future career.

The basic idea is simple:

**Tell us about yourself → Tell us your career goal → Get a roadmap.**

## What does it do?

The website asks the user some questions like:

* What is your education?
* What skills do you already know?
* What is your experience level?
* What are you interested in?
* How much time can you study?
* What is your career goal?
* What problems are you facing?

After that, it creates a step-by-step roadmap.

The roadmap includes things like:

* What to learn
* What to practice
* Projects to make
* How to prepare a resume
* How to prepare for interviews
* How to start applying for jobs

## Why did we make it?

As first-year students, we also found it confusing to understand what skills we should learn and in what order.

There are a lot of courses and technologies available, but beginners don't always know where to start.

So we tried to make a simple tool that gives a proper direction instead of just showing a list of skills.

## How it works

```text
User answers questions
        ↓
Career goal + current skills
        ↓
Backend processes the answers
        ↓
Personalized roadmap
        ↓
Learn → Practice → Projects
        ↓
Job Preparation
```

## Current Version

This is a **prototype made for a hackathon**.

It is not a fully finished AI product yet. The current version mainly demonstrates how personalized career roadmaps can be generated from user information.
